설치 및 사용 방법

macOS

  1. 화면 왼쪽 위 Apple 메뉴()에서 이 Mac에 관하여를 엽니다. ‘칩’이 보이면 Apple Silicon, ‘프로세서’가 보이면 Intel입니다
  2. Mac 종류에 맞는 설치 파일을 내려받고, 내려받은 .dmg 파일을 두 번 클릭해 엽니다
  3. 지음 설치.pkg를 두 번 클릭합니다
  4. 설치 도중 이 Mac의 관리자 암호를 입력합니다
  5. 화면 오른쪽 위 메뉴 막대의 입력 소스 메뉴에서 지음을 선택합니다

Windows

  1. Windows 베타 설치 파일을 내려받아 실행합니다
  2. 이 설치 파일은 아직 코드 서명 전이라 파란 경고 화면이 나타날 수 있습니다. 파일 이름이 Jieum-0.1.1-Windows-x64-setup.exe인지 확인한 뒤 추가 정보 → 실행을 선택합니다
  3. 사용자 계정 컨트롤에서 게시자가 알 수 없음인지 확인하고 예를 선택합니다
  4. 설치가 끝나면 작업 표시줄 오른쪽의 입력 표시기(한/A)에서 지음을 선택합니다. Win+Space로도 전환할 수 있습니다
