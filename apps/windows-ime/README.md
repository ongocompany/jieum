# 지음 Windows 입력기

Rust와 Windows Text Services Framework(TSF)로 만든 시스템 입력기입니다. 입력기 DLL은
로컬 엔진과 named pipe로 통신하고, 후보 창은 별도 프로세스에서 표시합니다.

## 설치

Windows 설치 프로그램은 준비 중입니다. 현재는 아래 개발용 빌드 절차만 제공합니다.
사용자용 설치 프로그램이 준비되기 전에는 DLL을 직접 등록해야 하므로 일반 사용자에게는
권장하지 않습니다.

## 개발용 빌드

지금은 x64 Linux에서 MinGW로 빌드합니다. Rust 1.85 이상, 32비트와 64비트 MinGW
툴체인, 각 아키텍처용 libhangul이 필요합니다.

```bash
apps/windows-ime/scripts/build.sh --host --release
```

입력기 DLL은 사용하는 앱과 비트수가 같아야 하므로 32비트와 64비트 빌드를 모두 만듭니다.
산출물은 `apps/windows-ime/target/` 아래에 생성됩니다.

## 키 조작

| 키 | 동작 |
|---|---|
| `1`~`9` | 해당 번호의 후보 확정 |
| `←` `→` | 이전·다음 후보로 이동 |
| `↓` `↑` | 후보 목록 펼치기·접기 |
| `Shift+↑` `Shift+↓` | 현재 앱에서 후보 창을 위·아래에 표시 |
| `Enter` | 선택한 후보 확정 |
| `Escape` | 후보 창 닫기 |
| 한자 키 | 한자 후보 모드와 한글 전용 모드 전환 |
| `Ctrl+Delete` | 선택한 사용자 조합 삭제 |

## 알려진 제한

아래한글은 현재 지원하지 않습니다. 아래한글에서 지음을 선택하면 조합이 깨질 수 있습니다.
`Alt+F2`를 눌러 「현재 글자판」과 「제1 글자판」을 한국어로 설정하면 한컴 입력기로
돌아갈 수 있습니다.

입력기 진단 로그에는 입력 내용, 조회 문자열, 확정한 단어를 기록하지 않습니다.
