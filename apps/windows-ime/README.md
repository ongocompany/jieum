# 지음 Windows 입력기

Rust와 Windows Text Services Framework(TSF)로 만든 시스템 입력기입니다. 입력기 DLL은
로컬 엔진과 named pipe로 통신하고, 후보 창은 별도 프로세스에서 표시합니다.

## 설치

Windows 10 또는 11(64비트)이 필요합니다.

[지음 웹사이트](https://jieum.ongo.kr/download/windows)에서 Windows 0.1.0 베타
설치 파일을 내려받습니다.

1. 내려받은 설치 파일을 실행합니다.
2. 이 설치 파일은 아직 Authenticode 코드 서명 전이라 Windows가 파란 경고 화면을
   띄울 수 있습니다. 파일 이름이 `Jieum-0.1.0-Windows-x64-setup.exe`인지 확인한 뒤
   `추가 정보`를 누르고 `실행`을 선택합니다.
3. 이어지는 사용자 계정 컨트롤에서 게시자가 `알 수 없음`인지 확인하고 `예`를 선택합니다.
4. 설치가 끝나면 작업 표시줄 오른쪽의 입력 표시기(`한`/`A`)에서 지음을 선택합니다.
   `Win+Space`로도 입력기를 전환할 수 있습니다.

설치 프로그램은 32비트·64비트 입력기와 엔진·사전을 함께 설치하고, 로그인할 때 엔진이
자동으로 시작되도록 설정합니다.

지음을 제거하려면 Windows `설정`에서 `앱` → `설치된 앱`을 열고 `지음`의 `제거`를
선택합니다. 사용자가 만든 조합과 설정은 다시 설치할 때 이어 쓸 수 있도록 남겨 둡니다.

## 개발용 빌드

지금은 x64 Linux에서 MinGW로 빌드합니다. Rust 1.85 이상, 32비트와 64비트 MinGW
툴체인, 각 아키텍처용 libhangul이 필요합니다.

```bash
apps/windows-ime/scripts/build.sh --host --release
```

입력기 DLL은 사용하는 앱과 비트수가 같아야 하므로 32비트와 64비트 빌드를 모두 만듭니다.
산출물은 `apps/windows-ime/target/` 아래에 생성됩니다.

## 키 조작

| 키 | 동작 |
|---|---|
| `1`~`9` | 해당 번호의 후보 확정 |
| `←` `→` | 이전·다음 후보로 이동 |
| `↓` `↑` | 후보 목록 펼치기·접기 |
| `Shift+↑` `Shift+↓` | 현재 앱에서 후보 창을 위·아래에 표시 |
| `Enter` | 선택한 후보 확정 |
| `Escape` | 후보 창 닫기 |
| 한자 키 | 한자 후보 모드와 한글 전용 모드 전환 |
| `Ctrl+Delete` | 선택한 사용자 조합 삭제 |

## 알려진 제한

아래한글은 현재 지원하지 않습니다. 아래한글에서 지음을 선택하면 조합이 깨질 수 있습니다.
`Alt+F2`를 눌러 「현재 글자판」과 「제1 글자판」을 한국어로 설정하면 한컴 입력기로
돌아갈 수 있습니다.

입력기 진단 로그에는 입력 내용, 조회 문자열, 확정한 단어를 기록하지 않습니다.
