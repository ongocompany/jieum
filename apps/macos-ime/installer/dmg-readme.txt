지음 0.1.0 베타는 Apple 실리콘 Mac(M1 이상)과 macOS 14 이상을 지원합니다.

지음 설치.pkg를 두 번 클릭하면 설치가 시작됩니다.

macOS가 개발자를 확인할 수 없다는 경고를 띄우면:

1. 지음 설치.pkg를 한 번 열어 경고를 확인합니다.
2. 시스템 설정을 열고 ‘개인정보 보호 및 보안’을 선택합니다.
3. 아래쪽 보안 영역에서 지음 설치.pkg의 ‘그래도 열기’를 선택합니다.
4. 관리자 암호를 입력하고 ‘열기’를 선택합니다.

설치 도중에도 이 Mac의 관리자 암호를 한 번 물어봅니다.
설치가 끝나면 화면 오른쪽 위 메뉴 막대의 입력 소스 메뉴에서 ‘지음’을 선택하세요.
